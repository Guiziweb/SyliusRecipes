  To enable the AI assistant, complete the setup in 3 steps:

  <comment>1. Install Symfony AI bundle and a provider bridge</>

     <comment>composer require symfony/ai-bundle symfony/ai-openai-platform</>

     Other bridges available: symfony/ai-gemini-platform,
     symfony/ai-anthropic-platform, symfony/ai-mistral-platform.

  <comment>2. Configure your provider in config/packages/ai.yaml</>

     <comment>ai:
         platform:
             openai:
                 api_key: '%env(OPENAI_API_KEY)%'</>

     Then add the key to <comment>.env.local</>:

     <comment>OPENAI_API_KEY=sk-...</>

  <comment>3. Enable the assistant on the grids you want</>

     Edit <comment>config/packages/guiziweb_sylius_grid_assistant.yaml</>
     and add the grid codes under <comment>enabled_grids</>.
